One sentence, up to 200 characters, on a small moment of wonder in everyday
life — an entry for the [make.fun bounty "Everyday Wonder, Two Days to Find the Line"](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3).

## Entry

> My neighbour waters a plastic plant every morning, and for three years I have not had the heart to tell her it never needed rain.

129 characters, one sentence.

## How it works

`main.py` (Python standard library only, no network) reads `entry.txt` next
to it, validates the gate — UTF-8, a single line, 1–200 characters, not only
whitespace — and writes it byte-for-byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output python3 main.py
cat /tmp/output/entry.txt
```

## Files

- `main.py` — entrypoint; reads `entry.txt`, validates it, writes the output.
- `entry.txt` — the entry sentence (129 characters).
